# Flexibility service for GEDERA proyect

This flexibility service is being designed to be exportable to other use cases (for now Ada Byron building use case).

## Controllable elemens:
- Air conditioning    (WIP)
- Battery             (WIP)
- Charging stations   (WIP)

## Algoritmos implementados:
- Breadth First Search (BFS)
- Deep First Search (DFS)
- BFS_poda
- DFS_poda 
- LowestSearch_Poda. A mix of deep and breadth search that retrieves all possible solutions minimizing price.
